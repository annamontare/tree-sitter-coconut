===
pattern-matching functions
===

match def f(_ + [x]):
    return x + 2

def g(Circle(radius=r)):
    return 2 * math.pi * (r ** 2)

---

===
conditional check in pattern-matching functions
===

match def f(x if x > 10):
    return x - 10

---

===
defaults in pattern-matching functions
===

match def f(_ + [x], _ + [y] = [1,2,3]):
    return x + y

===
return types in pattern-matching functions
===

match def f(Rect(x, y)) -> bool:
    return x > y
